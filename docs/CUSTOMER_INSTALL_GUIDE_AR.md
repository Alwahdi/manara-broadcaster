# دليل تركيب WIVA للعميل

هذا الدليل مخصص لصاحب الشبكة أو الفندق أو الكافيه أو المنشأة التي ستشغل WIVA داخل الشبكة المحلية.

## قبل البدء

- استخدم جهاز Windows ثابت داخل الشبكة، ويفضل أن يكون متصلًا بسلك شبكة.
- اجعل الجهاز يعمل طوال وقت الخدمة.
- تأكد أن الأجهزة التي ستشاهد القنوات أو المكتبة متصلة بنفس الشبكة.
- لا تفتح منافذ WIVA مباشرة على الإنترنت العام.

## التثبيت الأول

1. حمّل مثبت WIVA من صفحة الإصدارات.
2. ثبّت التطبيق وافتح WIVA.
3. ستظهر لك روابط محلية مثل:
   - رابط الإدارة: `http://<ip>:8788/admin`
   - رابط المشاهدة: `http://<ip>:8787`
   - رابط المكتبة: `http://<ip>:8788/library`
4. افتح رابط الإعداد من نفس الجهاز أو من جهاز آخر داخل نفس الشبكة.
5. أكمل خطوات الإعداد:
   - اسم الشبكة.
   - بيانات التواصل.
   - شعار الشبكة.
   - حساب الإدارة وكلمة مرور قوية.
   - منافذ البث والمكتبة.
   - اختيار عرض البث والمكتبة معًا أو منفصلين.

## بعد الإعداد

- افتح لوحة الإدارة لإضافة القنوات والمكتبة.
- شارك رابط المشاهدة أو QR مع المشتركين داخل الشبكة فقط.
- احتفظ بكلمة مرور الإدارة في مكان آمن.

## إضافة قناة بث مباشر

1. افتح لوحة الإدارة.
2. اختر القنوات أو البث المباشر.
3. أضف اسم القناة والتصنيف.
4. اختر جهاز الالتقاط والفيديو والصوت إن كانت قناة capture.
5. احفظ القناة وافتح رابط المشاهدة للتأكد.

## إضافة IPTV

1. افتح قسم IPTV من لوحة الإدارة.
2. أضف قناة أو استورد قائمة إذا كانت لديك صلاحية استخدامها.
3. فعّل القنوات التي تريد إظهارها للمشتركين.
4. جرّب التشغيل من صفحة المشاهدة.

لا تضف مصادر لا تملك حق استخدامها.

## إضافة مكتبة

1. افتح قسم المكتبة في لوحة الإدارة.
2. أضف مجلدًا من الأقراص المتصلة بالجهاز.
3. ابدأ الفهرسة من لوحة الإدارة.
4. سيظهر المحتوى للمشتركين كأقسام ومجلدات داخل مكتبة الشبكة.

إذا فصلت قرصًا خارجيًا، سيبقى المحتوى معروفًا لكنه يظهر غير متاح حتى يعود القرص.

## الجدار الناري والشبكة

- اسمح بمنافذ WIVA داخل الشبكة المحلية فقط.
- تأكد أن أجهزة المشتركين يمكنها الوصول إلى IP جهاز WIVA.
- استخدم شبكة Gigabit إذا كان عدد المشاهدين كبيرًا.

## التحديثات

- WIVA يدعم التحديث من GitHub Releases.
- قبل التحديث التجاري الواسع، اختبر الإصدار على جهاز واحد.
- التحديث يجب ألا يحذف الإعدادات أو القنوات أو المكتبة.
